# Security Policy

## Supported versions

This repository is an active portfolio project. Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please **do not open a public issue** for suspected vulnerabilities.

Send a private report to **krican07@gmail.com** with:

- the affected component and version or commit
- clear reproduction steps
- the potential impact
- any suggested mitigation
- whether the issue has already been disclosed elsewhere

Do not include real credentials, personal data, or destructive proof-of-concept payloads. Please allow reasonable time for investigation and remediation before public disclosure.

## Secrets

Never commit API keys, tokens, private keys, connection strings, or completed environment files. Use local environment variables and replace any exposed credential immediately.
